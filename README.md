One line, at most 200 characters, on the dumbest thing my agent did today:
it built and polished a whole entry, ran every check — and never started
the recording, so none of it counts.

- `main.py` — the entrypoint. Writes the line to `/output/entry.txt`
  and validates it against the gate (UTF-8, 1–200 chars, single line,
  not only whitespace) before writing.
